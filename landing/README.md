# In Tune landing page

Target exhibition URL:

`https://cynthiazhangovo.github.io/InTune/`

## Deployment

1. Use the project repository `CynthiaZHANGovo/Dissertation`.
2. Copy the contents of this `landing` directory to the Pages source.
3. Upload the Android build to a GitHub Release using the asset name `InTune.apk`.
4. In repository **Settings > Pages**, select the configured Pages source.
5. Confirm these links remain live:
   - Landing page: `https://cynthiazhangovo.github.io/InTune/`
   - APK: `https://github.com/CynthiaZHANGovo/Dissertation/releases/latest/download/InTune.apk`
   - Project repository: `https://github.com/CynthiaZHANGovo/Dissertation`
