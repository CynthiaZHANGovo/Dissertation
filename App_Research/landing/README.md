# In Tune landing page

Target exhibition URL:

`https://cynthiazhangovo.github.io/InTune/`

## Deployment

1. Create a public GitHub repository named `InTune` under `CynthiaZHANGovo`.
2. Copy the contents of this `landing` directory to the repository root.
3. Upload the Android build to a GitHub Release using the asset name `InTune.apk`.
4. In repository **Settings > Pages**, select **Deploy from a branch**, then choose `main` and `/ (root)`.
5. Confirm these links remain live:
   - Landing page: `https://cynthiazhangovo.github.io/InTune/`
   - APK: `https://github.com/CynthiaZHANGovo/InTune/releases/latest/download/InTune.apk`

The QR code points to the landing page URL, so new APK releases do not require
reprinting the exhibition QR.
